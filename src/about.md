Intuitive Counter is David Walend's blog about Scala, AI, graphs, and coding.

It has started and stopped a few times. The current run is built with
[Eleventy](https://www.11ty.dev/) and published to GitHub Pages; earlier entries
came from a Jekyll site, from [Hashnode](https://dwalend.hashnode.dev), and
before that from a blog on java.net.

posts are public domain; take them with no obligation. The
[source of the site](https://github.com/dwalend/blog) is MIT.
